How it works

Position labels

Each digit position is labeled from 0 to N-1 , left to right, where N is the total number of digits.

Digit value

The value stored at position i declares how many times the digit i should appear across the entire number.

Frequency check

For every position i , we count occurrences of digit i . The digit at position i must match that count exactly.

Leading zeroes

Numbers are treated as written with no leading zeroes. So 1210 has four positions, not five.
